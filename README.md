# Momo Whisper

🍡 A macOS menu-bar app: hold **Fn** to dictate, **Fn+Shift** to translate, or highlight any text to
translate it in place. Thai / English + 16 languages, tone control — powered by Groq.

**→ Download & docs: https://nabhak.github.io/Whisper-App-Momo-Edition/**

**Install:** [download the latest build](https://github.com/Nabhak/Whisper-App-Momo-Edition/releases/latest/download/Whisper-Momo.zip),
unzip, drag **Momo Whisper** to Applications, right-click → **Open** the first time, allow Microphone +
Accessibility, then paste a free [Groq](https://console.groq.com) key in Settings.

Built on the original [**Whisper** by Gamezxz](https://github.com/Gamezxz/WhisperApp) 🙏 · MIT License.
