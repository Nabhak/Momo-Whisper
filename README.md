# Momo Whisper

🍡 A macOS menu-bar app: hold **Fn** to dictate, **Fn+Shift** to translate, or highlight any text to
translate it in place. Thai / English + 16 languages, tone control — powered by Groq.

**→ Download & docs: https://nabhak.github.io/Momo-Whisper/**

**Install:** [download the latest build](https://github.com/Nabhak/Momo-Whisper/releases/latest/download/Momo-Whisper.zip),
unzip, drag **Momo Whisper** to Applications, right-click → **Open** the first time, allow Microphone +
Accessibility, then paste a free [Groq](https://console.groq.com) key in Settings.

## About this repository

This is the **website and releases** repository for Momo Whisper. It contains the website (`docs/`) and
the downloadable app builds (GitHub Releases). It does **not** contain the app's source code.
